# ゴマエビちゃん (ホーム画面のマスコット)

ここに透過PNGを置くと、本体のホーム画面の右下に出ます。無ければ何も出ません。

| ファイル名 | いつ出るか |
|---|---|
| `idle.png` | ふだん |
| `happy.png` | スマホ・PCから何か届いた時 (8秒間)。無ければ `idle.png` のまま |

- 白ふち付きの透過PNG (全身の立ち絵) をそのまま置けば、画面の縦いっぱい (134px) に縮めます。
  横に広いポーズ (腕を上げているなど) は幅66pxに収まるよう少し小さめに。余白は自動で切ります
- 右の説明文は、ゴマエビちゃんに重ならない幅に自動で縮みます
- 置いたら HEXA CLIP を起動し直してください
- `*.png` は git に入れない設定です (イラストが公開リポジトリに上がらないように)。
  PCから本体へは `scp idle.png happy.png cpz:~/hexaclip/assets/mascot/` などで送ります
