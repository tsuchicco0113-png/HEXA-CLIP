# HEXA CLIP

**スマホやPCから、M5Stack CardputerZero へコードや資料を渡すためのアプリ。**

小さいキーボードで長いコマンドやコードを打つ代わりに、スマホ・PCから送って、本体で使います。

- 送ったテキストは、本体のどのアプリでも **fn+V** でキー入力として打ち込める
- **fn+H** で、どのアプリの上でも履歴のパネルが出る (アプリを開かずに選んで打ち込める)
- ファイル (コード・PDF・画像) は本体の `~/clip/` に名前付きで届く
- 本体からスマホ・PCへ送り返すこともできる

## はじめる (3ステップ)

**1. 本体にインストール**

```bash
git clone https://github.com/tsuchicco0113-png/HEXA-CLIP.git ~/hexaclip
cd ~/hexaclip && sh install.sh      # sudo は付けない
```

初回は `sudo reboot` で再起動すると、ホーム画面に **HEXA CLIP** アイコンが出ます。

**2. スマホをつなぐ**

本体の HEXA CLIP を開き、ホーム画面で `接続` を選んで、出てきたQRをスマホのカメラで読みます (同じWi-Fi)。
QRが使えなければ、表示される URL を開いて PIN を入力します (ログインは30日間有効)。

**3. 送る → 本体で使う**

スマホ画面の入力欄にコードを貼って `CPZへ送る`。本体で打ちたい場所にカーソルを置いて **fn+V**。
古いものを選びたい時は **fn+H** でパネルを出して、選んで `ENTER`。

## ふだんの使い方

### スマホ (ブラウザ)

| 操作 | 内容 |
|---|---|
| **CPZへ送る** | 入力欄の内容を送る。本体の fn+V で打ち込める |
| 📷 撮って読む | スマホで撮影 → 読みたい所を指でなぞって囲む → `読み取る`。文字の読み取りは本体で行い、結果が入力欄に入る。直して送る |
| 📎 ファイル | ファイルをそのまま送る (複数可)。PCのブラウザならドラッグ&ドロップでも |
| 🏷 名前 | 入力欄の内容に名前を付けて送る (例 `main.py` → 本体の `~/clip/main.py`) |
| 履歴 | `コピー` / `編集` / `貼付用` (fn+V の対象にする) / `DL` / `削除` / ☆ ピン留め |

- 本体側の変更はすぐスマホに反映されます
- 一番下の「PCから使う」に、PC用コマンドのダウンロードと設定方法が出ます

### 本体: どのアプリからでも (fn+V / fn+H)

HEXA CLIP アプリを開かなくても、CLI などどのアプリの中でも使えます。

| キー | 内容 |
|---|---|
| **fn+V** | 最新 (`fn+V` 印) をすぐ打ち込む |
| **fn+H** | 今の画面の上に履歴パネル (★ピン留め → 最近の順)。`↑↓` で選んで `ENTER` で打ち込む / `1`〜`6` ですぐ / `ESC` で閉じる |

- スマホやPCから何か届くと、どのアプリの中でも画面の上に1〜2秒「受信」の帯が出ます (設定で止められる)
- パネルや帯を出している間だけ、ランチャー (CLIもランチャーが描いている) を一時停止して上に描き、
  閉じたら元の画面に戻します。ファイル (PDFなど) はパネルに出ません

### 本体 (ホーム画面の HEXA CLIP)

起動すると **ハニカムのホーム画面**。六角形を方向キーで選んで `ENTER` (数字の `1`〜`4` で直接も)。
各画面から `ESC` でホームに戻ります。画面下に、その画面で使えるキーが出ます。

| 六角形 | 内容 |
|---|---|
| **1 履歴** | 受け取ったものの一覧。`fn+V` 印が貼り付けられる項目。`ENTER` で全文 → もう一度 `ENTER` でメニュー |
| 2 接続 | スマホ用のQRとPIN |
| 3 カメラ | おまけ (下の「おまけ: 本体カメラ」) |
| 4 設定 | 受信したら (通知だけ / 本文を開く)、fn+V の改行、ほかのアプリ中に受信 (帯を出す / 出さない)、ゴマエビちゃん (表示する / しない)、カメラの設定 |

ホーム画面の右側には、今 fn+V で貼れる内容と、新着の数が出ます。
`assets/mascot/` に立ち絵を置くと、マスコットのゴマエビちゃんが右下に出て、何か届くと表情が変わります
(置き方は `assets/mascot/README.md`。設定の「ゴマエビちゃん」で消せます)。

全文表示のメニュー: **貼付用にする** / 編集 / ファイルに保存 / 本体で実行 / QRで表示 / ピン留め / 削除

- 方向キーは本体の流儀と同じ **F(↑) X(↓) Z(←) C(→)**。`ESC` で戻る (ホームでは確認して終了)
- メニューの右に出ている英字は近道キー (例: 全文表示で `V` を押すと、すぐ貼付用)。履歴では `/` で検索

### PC (hexaclip コマンド)

Python 3 があれば Windows / Mac / Linux で使えます。

```bash
curl -O http://<CPZ>:8080/hexaclip.py                  # 本体から取ってくる
python hexaclip.py setup http://<CPZ>:8080 <TOKEN>     # 最初に1回 (TOKEN はスマホ画面の「PCから使う」)

python hexaclip.py send main.py 資料.pdf   # ファイルを送る
git diff | python hexaclip.py push         # 標準入力を送る
python hexaclip.py push --clip             # PCのクリップボードを送る
python hexaclip.py paste --clip            # 最新をPCのクリップボードへ
python hexaclip.py get                     # 最新のファイルを保存 (同名は (1) を付けて上書きしない)
```

本体の上でも **同じ `hexaclip` コマンド** が使えます (設定不要)。

```bash
hexaclip paste > main.py     # スマホから送ったコードを保存
hexaclip paste | python3     # そのまま実行
hexaclip push < log.txt      # スマホ/PCへ送る
hexaclip send log.txt        # ファイルとして送る (スマホ/PCの履歴からDL)
```

## もう少し詳しく

### fn+V で貼り付け

本体のどのアプリでも、**fn を押しながら V** で、HEXA CLIP の最新 (`fn+V` 印) の内容をキー入力として打ち込みます。
古い項目を貼りたいときは、履歴で開いて `貼付用にする` (スマホなら `貼付用`)。

- 打てるのは英数字と記号だけ。日本語は飛ばします (貼付用にした時に件数を表示)
- 改行は ENTER として打たれます (シェルでは1行ずつ実行される)。末尾の改行は打ちません。
  設定「fn+V の改行」を「打たない」にすると、空白でつないで1行にまとめます
- 打ち込み中に `ESC` で中止。最大4000文字
- fn+V / fn+H で `v` `h` が一瞬入りますが、打ち込む前に自動で消します
- 止める: `sudo systemctl disable --now hexaclip-paste`
  (fn+H のパネルと受信の帯だけ止めるなら、サービスの起動オプションに `--no-panel`)

### ファイル

- 本体の `~/clip/<名前>` に保存。同じ名前があれば1つ前を `~/clip/.prev/` に残します
- UTF-8のテキスト (256KB以下) は履歴に本文も入り、本体で表示・編集・fn+V できます。
  Windowsの改行 (CRLF) とBOMは自動で直します
- PDF・画像などは履歴の `DL` で取り出せます。上限100MB
- 履歴を削除しても `~/clip/` のファイルは残ります

### 本体で実行

全文表示のメニューで `本体で実行` → `TAB` で python3 / sh を選んで `ENTER`。

- `~/clip/` に保存してから実行します。出力は画面に流れ、`ESC` で停止 (子プロセスごと)
- 終わったら `S` で出力を HEXA CLIP へ送れます (結果をスマホ/PCで見る)
- 入力 (`input()` など) は使えません

### ピン留め・検索

- ★ を付けた項目は、履歴が500件を超えて古いものが消えても残ります。スマホでは上に「ピン留め」欄で出ます
- 検索は本文とファイル名が対象。空白で区切ると全部を含むものだけ

### QRで渡す (Wi-Fiなし)

全文表示のメニューで `QRで表示`。本体の画面に出たQRをスマホのカメラで読めます (700バイト程度まで)。

### ショートカット / 共有シートから送る

`hexaclip token` (本体で実行) に出るトークンを、iOSのショートカット (「URLの内容を取得」) などに設定します。

```
送る:      POST http://<CPZ>:8080/api/items     本文=送りたい文字
           Authorization: Bearer <TOKEN> / Content-Type: text/plain
受け取る:  GET  http://<CPZ>:8080/api/latest    (同じ Authorization)
```

avahi が動いていれば `http://<ホスト名>.local:8080/` でも届きます (`接続` 画面と `hexaclip pin` に表示)。

## おまけ: 本体カメラ

ホームの `カメラ` で、本体カメラを使って文字やQRを読みます。カメラはこの画面でだけ動きます。

- `ENTER`: 文字を読む (Tesseract)。結果は編集画面で直して送ります
- `Q`: QR・バーコードを読む (誤読がないのでおすすめ)
- `↑↓`: ズーム。枠の色と FOCUS バーでピント確認 (緑=良)

本体カメラは固定焦点で、小さい文字 (PC画面など) は苦手です。**文字の読み取りはスマホの「📷 撮って読む」の方が確実**です
(読み取り自体は本体で行うので、画像が外部に出ることはありません)。

- 30〜40cm 程度離して撮ります。暗い背景 (ダークモードの画面) は自動で反転します
- 自信のない文字は橙色+下線で残ります (直すと色が消える)
- カメラのない CardputerZero-Lite でも、カメラ以外の機能はそのまま使えます

## コマンド一覧 (hexaclip)

| コマンド | 内容 |
|---|---|
| `send FILE...` | ファイルを名前付きで送る |
| `push [TEXT]` / `push --clip` | テキストを送る (省略時は標準入力) / PCのクリップボードを送る |
| `paste [N]` / `paste --clip` | 最新 (N番目) を出力 / PCのクリップボードへ |
| `get [ID] [-o DIR]` | ファイルとして保存 |
| `list [N]` / `find 語...` | 一覧 / 検索 |
| `top ID` / `rm ID` / `star ID` / `unstar ID` | fn+V の対象にする / 削除 / ピン留め / 外す |
| `pin` / `qr` | スマホ用のURLとPIN / QRで (本体で実行) |
| `token [reset]` | PC・ショートカット用のトークン (本体で実行) |
| `logout-all` | 全端末をログアウト (本体で実行) |
| `setup URL TOKEN` / `info` | PCの初期設定 / 接続状態 |

旧コマンド `czclip` も互換用に残っています。

## セキュリティ

- Web画面は同一LAN向け (HTTP)。6桁PIN、5回失敗で60秒ロック
- トークンを知っている端末は読み書きできます。漏れたら `hexaclip token reset`
- `127.0.0.1` からのアクセスは認証不要 (本体の上のコマンド・アプリ用)
- PIN再発行と全端末ログアウト: `python3 ~/hexaclip/czclipd.py --reset-pin` → `sudo systemctl restart hexaclip`

## 困ったとき

- 本体のランチャーが固まったまま: `sudo pkill -CONT -f APPLaunch`
  (`hexaclip-paste` は起動時にも自動でランチャーを再開します)
- キーが効かない: `hexaclip-ocr --debug-keys` でコードを確認、`--keys keys.json` で上書き
- サーバーの状態: `systemctl status hexaclip` / `systemctl status hexaclip-paste`

## 動作環境

- M5Stack CardputerZero / CardputerZero-Lite (Raspberry Pi CM0 / Debian aarch64)
- Python 3、Pillow、numpy、Tesseract (`tesseract-ocr-jpn`)、zbar-tools、Picamera2 (カメラ使用時)
